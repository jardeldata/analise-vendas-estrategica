# 📊 Análise de Vendas Estratégica

## 🎯 Objetivo

Este projeto tem como objetivo analisar dados de vendas para gerar insights estratégicos e apoiar a tomada de decisão baseada em dados.

---

## 🧠 Etapas do Projeto

* Limpeza e tratamento de dados
* Criação de indicadores (KPIs)
* Análise exploratória (EDA)
* Análises cruzadas
* Formulação de hipóteses
* Geração de insights estratégicos
* Proposta de plano de ação

---

## 📊 Principais Insights

* Forte concentração de receita nas regiões West e East
* Baixo desempenho da região South
* Categoria Technology como principal geradora de receita
* Crescimento consistente ao longo do tempo
* Oportunidade de aumento do ticket médio

---

* Python

* Matplotlib
